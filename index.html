Mes cibles nutrition

pour la règle 80/20

Les protéines et les lipides se calculent sur ton dernier poids ; les glucides complètent les calories restantes. La règle 80/20 : au plus 20 % de repas plaisir, sans culpabilité.

Mes cibles quotidiennes

Synchroniser mes pas

Sur iPhone, un raccourci peut envoyer chaque jour ton nombre de pas de l'app Santé vers le carnet.

  1. Ouvre l'app Raccourcis, onglet Automatisation, puis + : « Heure de la journée », par exemple 21:30, tous les jours, « Exécuter immédiatement ».
  2. Ajoute l'action Rechercher des échantillons de santé : type « Nombre de pas », date de début « Aujourd'hui », regrouper par « Jour ».
  3. Ajoute Arrondir le nombre, puis Texte avec le lien ci-dessous suivi du nombre arrondi.
  4. Termine par Ouvrir les URL. Le carnet s'ouvre et enregistre tes pas du jour.
Lien à mettre dans l'action Textehttps://claude.ai/artifact/9aT9Z3e6pSqFJ3iMb32aov#pas-

Exemple : …#pas-8540 enregistre 8 540 pas pour aujourd'hui. Il faut être connecté à ton compte Claude sur le téléphone. Sur Android, il n'existe pas d'équivalent intégré : la saisie se fait à la main.
